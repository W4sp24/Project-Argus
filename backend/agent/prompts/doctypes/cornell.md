Write Cornell-style notes for this material. Use exactly these sections.

`## Cues` — one question per line, each answerable from the Notes section
below and from nothing else. These are used with the notes covered up, so
write questions that make the reader recall something, not questions they can
answer yes or no.

`## Notes` — the detailed notes as nested bullets, in the document's order,
grouped so that everything answering one cue sits together.

`## Summary` — at most five sentences, written as if explaining the material
to someone who has not read it.
