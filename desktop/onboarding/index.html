Everything stays here

Argus reads and writes plain Markdown in an Obsidian vault on this computer. Your notes are never uploaded, and the folder stays yours — you can open it in Obsidian, or in any text editor, at any time.

One thing needs to be installed before it can work, and you'll pick how the AI runs. Let's check.

Only git is required — it's what lets Argus snapshot your vault before it changes anything, so every edit can be undone. The rest are the different ways to run the AI, and you only need one of them. You can add one later instead.

How should the AI run?

Argus needs a model to answer questions about your notes, plan your day, and build practice exams. Three ways, and you can change or mix them any time under System → Models.

FREE A model on this computer (Ollama)
Costs nothing, works offline, and your notes never leave this machine. Needs a reasonably modern PC — Argus will tell you which models fit yours and download one for you.
Get Ollama →
PAID A hosted API key
Works on any machine, however old, because the work happens on someone else's servers — which does mean excerpts of your notes are sent to them. Groq, Together, Fireworks, OpenRouter, or Anthropic. Usually a few dollars a month.
SUB Claude Code
Uses a Claude subscription you already pay for. Note excerpts are sent to Anthropic.
Get Claude Code →
